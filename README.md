## Setting Up a New Machine

### 1. Install NixOS with the graphical installer

Boot from a NixOS USB stick and complete the installation using the graphical
installer (Calamares). This handles partitioning, user creation, and the initial
system configuration.

### 2. Clone this repo and grab the hardware config

After the first boot into the fresh install:

```bash
# Install git temporarily if not available
nix-shell -p git

# Clone the config
git clone <repo-url> ~/nixos-config
cd ~/nixos-config

# Create a host directory and copy the hardware config generated by the installer
mkdir -p hosts/my-new-host
cp /etc/nixos/hardware-configuration.nix hosts/my-new-host/
```

### 3. Create the host configuration

Create `hosts/my-new-host/configuration.nix` importing the features you need.
Use an existing host as a template — pick features from `features/` as needed.

### 4. Register the host in flake.nix

Add a new entry under `nixosConfigurations`:

```nix
"my-new-host" = nixpkgs.lib.nixosSystem {
  system = "x86_64-linux";
  specialArgs = { inherit inputs; };
  modules = [
    ./hosts/my-new-host/configuration.nix
  ];
};
```

### 5. Complete one-time setup steps

Before the first rebuild, perform any manual setup required by the features
you're enabling. See the [One-Time Setup](#one-time-setup) section below.

This avoids failed services on first boot (e.g. davfs2 needing credentials
that don't exist yet).

### 6. Apply the flake configuration

```bash
sudo nixos-rebuild switch --flake ~/nixos-config#my-new-host
```

This replaces the installer-generated config with the flake-managed one.

## Rebuilding

From the machine being managed:

```bash
# Using nh (recommended — NH_FLAKE is set in session variables)
nh os switch

# Or manually:
sudo nixos-rebuild switch --flake /home/hector/nixos-config#$(hostname)
```

## One-Time Setup

These steps must be done manually once per machine after the first rebuild.

### WebDAV credentials (machines using `features/apps/webdav`)

davfs2 reads credentials from `/etc/davfs2/secrets`. Create it before the first
rebuild that includes the webdav feature:

```bash
sudo mkdir -p /etc/davfs2
sudo bash -c 'cat > /etc/davfs2/secrets << EOF
/mnt/saves  YOUR_WEBDAV_USERNAME  YOUR_WEBDAV_PASSWORD
EOF'
sudo chmod 600 /etc/davfs2/secrets
sudo chown root:root /etc/davfs2/secrets
```

The mount at `/mnt/saves` uses `x-systemd.automount` — it will connect on first
access rather than blocking boot if the server is unreachable.

## Maintenance

### Updating flake inputs

```bash
nix flake update
```

Or update a single input:

```bash
nix flake update nixpkgs
```

Then rebuild to apply.

### Garbage collection

Remove old generations and free disk space:

```bash
# Delete generations older than 7 days
sudo nix-collect-garbage --delete-older-than 7d

# Also remove old boot entries
sudo /run/current-system/bin/switch-to-configuration boot
```

### Listing generations

```bash
nixos-rebuild list-generations
```

### Rolling back

```bash
sudo nixos-rebuild switch --rollback
```

Or pick a specific generation from the systemd-boot menu at boot time.

## Adding a Feature to a Machine

1. Import the feature's `system.nix` in the host's `configuration.nix` imports list.
2. If the feature has a `user.nix`, import it under `home-manager.users.<name>.imports`.
3. Rebuild.

## Notes

- `stateVersion` should be set once when a machine is first installed and never changed.
- The `NH_FLAKE` session variable lets `nh os switch` find this repo without arguments.
- Kernel patches live in `patches/` and are referenced from host configs as needed.
